# LayerLab Studio 2.0

Независимый браузерный растровый редактор. Чистый HTML/CSS/JavaScript, без сторонних библиотек, аккаунтов, отслеживания и серверов. Не связан с Adobe Photoshop.

## Запуск

Откройте `index.html` в современном Chrome, Edge или Firefox. Для публикации GitHub Pages положите `index.html`, `style.css`, `app.js` в корень репозитория; Settings → Pages → Deploy from a branch → main → /(root).

## Возможности

- Редактирование на холсте до 4096 × 4096 пикселей
- Несколько растровых слоёв: перемещение, видимость, прозрачность, наложение, порядок, дублирование
- Кисть, ластик, линия, прямоугольник, эллипс, заливка смежных областей, линейный градиент, текст, пипетка
- Прямоугольное выделение, Ч/Б и инверсия выбранного участка, яркость/контраст/насыщенность
- Поворот и отражение слоя, размер холста, объединение видимых слоёв
- Импорт PNG/JPG/WebP и других форматов, поддерживаемых браузером; экспорт PNG/JPG/WebP
- История до 24 операций; редактируемый проект JSON
- Клавиши: V перемещение, B кисть, E ластик, M выделение, K заливка, L линия, G градиент, T текст, I пипетка, Ctrl+D снять выделение, Ctrl+Z/Ctrl+Y история, Ctrl+S сохранить проект.

## Известные ограничения

- Это не полная замена Adobe Photoshop: нет PSD, CMYK, смарт-объектов, векторных контуров, корректирующих слоёв, масок, AI-функций и сложного выделения.
- Текст растеризуется после ввода, а не остаётся редактируемым текстовым объектом.
- Выделение действует на пиксельные коррекции, но не на все рисующие инструменты.
- Экспорт JPG включает белый фон; сохранение проектов с большими холстами может занимать много памяти.
- Операция поворота вращает содержимое внутри исходного холста; края могут быть обрезаны.
- Используйте только изображения, на которые у вас есть права.
